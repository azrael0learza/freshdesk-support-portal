# Freshdesk Support Portal

> Custom Freshdesk Support Portal homepage template built with HTML, Freshdesk Liquid templating, Bootstrap-style classes, and inline SVG icons.

---

## Overview

This project contains the custom homepage template used for the **Freshdesk Support Portal**.

The template combines standard **HTML markup** with **Freshdesk's Liquid-style templating syntax** to create a customised customer support.

It provides a central support hub where users can:

- Search the knowledge base
- Browse frequently asked questions
- Submit a support ticket
- Browse support articles
- Access community forums
- View popular articles
- View trending topics

---

## Homepage Structure

The homepage is organised into several sections:

| Section | Purpose |
|---|---|
| Search Banner | Allows users to search the Freshdesk knowledge base |
| Frequently Asked Questions | Provides quick access to common questions |
| Submit a Ticket | Direct link to the support ticket form |
| Solutions | Provides access to the Freshdesk knowledge base |
| View All Articles | Links users to the available support articles |
| Forums | Displays available community discussion areas |
| Popular Articles | Shows frequently accessed support articles |
| Trending Topics | Displays popular community discussions |

---

## Technologies

This template uses:

- **HTML5** — Page structure and markup
- **Freshdesk Liquid** — Dynamic content and conditional logic
- **Bootstrap-style classes** — Responsive layout and spacing
- **SVG** — Custom inline icons
- **Git/GitHub** — Version control and source management
